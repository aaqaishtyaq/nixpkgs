# nixpkgs

dotfiles managed via nix

## How to install

Install vanilla nix through determinate system's installer

```bash
curl --proto '=https' --tlsv1.2 -sSf -L https://install.determinate.systems/nix | sh -s -- install --diagnostic-endpoint=''

# Install Determinate Nix?
# Selecting 'no' will install Nix from NixOS instead.
# Proceed? ([Y]es/[n]o/[e]xplain):
# => Select No here
```
